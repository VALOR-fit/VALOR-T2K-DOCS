\section{Summary of changes included in version 2 of T2K-TN-183 (released on Feb. 05, 2014)}

This section is designed to allow readers to keep track of the changes between versions of T2K-TN-183.
Table, figure, equation, footnote or citation numbers shown in black refer to version of 1,
{\color{red}whereas the numbers shown in red refer to version of 2}.
Both numbers are shown where possible.

\begin{itemize}

\item Various additions were made to Sec.\ 7, the most important being:

  \begin{itemize}
  \item Finalised 2D Feldman-Cousins contours for both normal and inverted mass hierarchies
  \item Finalised 1D Feldman-Cousins limits for both normal and inverted mass hierarchies
  \item Added Run 1+2+3 and Run 4 only results for the normal mass hierarchy
  \item Added a sensitivity study for the normal mass hierarchy
  \end{itemize}
  
\item The value and error of $\sin^2\theta_{12}$ has been updated to agree with the PDG2012 value ($\sin^2\theta_{12} = 0.312$, $\delta\sin^2\theta_{12} \sim 5.8\%$).
  
\end{itemize}
