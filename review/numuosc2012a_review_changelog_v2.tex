\section{Summary of changes included in version 2 of T2K-TN-141 (released on Jan. 23, 2013)}

This section is designed to allow readers to keep track of the changes between versions of T2K-TN-141.
Table, figure, equation, footnote or citation numbers shown in black refer to version of 1,
{\color{red}whereas the numbers shown in red refer to version of 2}.
Both numbers are shown where possible.

\begin{itemize}

\item
Added a footnote, quoting the Run 1+2+3 best-fit values obtained by allowing
$sin^{2}(2\theta_{23})$ to enter into the unphysical region (Boris/Neil). \checkmark

\item
When comparing the T2K Run 1+2+3 analysis contour, with the contours obtained
by the latest MINOS and SK analyses, it is indicated whether the analysis is done 
in a 2- or 3-flavour framework (Boris). \checkmark

\item
Added correct references to NA61 (Boris). \checkmark

\item
Added a plot (Fig. {\color{red}(16)}) 
showing an example of a typical systematic parameter response function; 
it shows the event weights 
obtained by tweaking $M_{A}^{QE}$ for $\nu_{\mu}$-CCQE events in a particular
reconstructed and true energy bin.  
Some ~7,500 response functions were checked and they all look reasonable.
\checkmark

\item
In all reconstructed energy spectra, data points are now shown for all bins with 0 events (Jan). \checkmark

\item
Modified Table 11 so that the maximum systematic shifts are given relative to the
statistical error at the oscillation point where the maximum shift occurs (Jan). \checkmark

\item
Change the y axis label from `number of events' to `number of events per bin in several plots (Kate). \checkmark

uncertainties (Neil/Anselmo). \checkmark

\item

this analysis predicts 204.75 $\pm$ 17.02 (syst) 1 $\mu$-like ring events in SuperK.
The quoted error was updated using the larger toy-MC ensemble mentioned above.
The updated number is 204.75 $\pm$ 16.75 (syst). \checkmark

and, potentially, this is confusing  (Anselmo). \checkmark

\item
The `2+N' best-fit $|{\Delta}m^{2}_{32}|$ value was incorrectly rounded-off to
$2.442 \times 10^{-3} eV^2/c^4$ instead to $2.443 \times 10^{-3} eV^2/c^4$
(from $2.4427 \times 10^{-3} eV^2/c^4$ returned by MINUIT).
This has now been corrected.
However, as mentioned earlier in this document in a reply to Boris P.,
the best-fit numbers are quoted with this precision only for internal T2K
consumption and in order for small differences between fit variants to be seen.
For any external communication of our reslts, it is appropriate to round off 
this number to $2.44 \times 10^{-3} eV^2/c^4$. \checkmark

\item
Figs. 193  {\color{red}(197)} and 241  {\color{red}(245)} in Appendix F and
Tables 51 {\color{red}(51)} and 99 {\color{red}(99)} in Appendix E were regenerated.
Before, a $\pm$3$\sigma$ range was used.
This required ``extrapolating'' $f_{SF}$ beyond the [0,1] range.
As it was decided that $f_{SF}$ will be strictly limited in the [0,1] range,
the figures and tables were updated using only the nominal value ($f_{SF}$=0) and
+1$\sigma$ variation ($f_{SF}$=1). \checkmark

\item
Missing values of oscillation parameters were added in several plot captions in Appendix B. \checkmark

\item
Improved articulation in a few places. 
Fixed various other minor spelling mistakes, missing dots etc. \checkmark
