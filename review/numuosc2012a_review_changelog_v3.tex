\section{Summary of changes included in version 3 of T2K-TN-141 (released on Jan. 31, 2013)}

This section is designed to allow readers to keep track of the changes between versions of T2K-TN-141.
Table, figure, equation, footnote or citation numbers shown in black refer to version of 2,
{\color{red}whereas the numbers shown in red refer to version of 3}.
Both numbers are shown where possible.

\begin{itemize}

\item
One of the questions received by the review committee was about the Run 1+2+3 best-fit values 
that would have been obtained had $sin^{2}(2\theta_{23})$ been allowed to enter into the unphysical region. 
The initial reply to the reviewers, and footnote 7 {\color{red}(7)}) added in version 2 of T2K-TN-141, were incorrect.
Some protection against $sin^{2}(2\theta_{23})$ values greater than 1 still lurked within the VaLOR analysis code
when the fit was repeated without the physical boundary. We also realized that an answer can not be provided in a 3-flavour
framework due to the existence of a $\sqrt{1-sin^{2}(2\theta_{23})}$ term in the oscillation probabilities.
Version 3 of T2K-TN-141, as well as the reply to the review committee recorded in this document, were updated 
with the correct Run 1+2+3 best-fit values in the absence of the boundary at  $sin^{2}(2\theta_{23})$ = 1.
Only a 2-flavour result is quoted.

\end{itemize}
