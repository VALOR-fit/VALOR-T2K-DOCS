\section{Summary of changes included in version 5 of T2K-TN-141 (released on May 17, 2013)}

This section is designed to allow readers to keep track of the changes between versions of T2K-TN-141.
Table, figure, equation, footnote or citation numbers shown in black refer to version of 4,
{\color{red}whereas the numbers shown in red refer to version of 5}.
Both numbers are shown where possible.

\begin{itemize}

\item
  Include updated contours for fits to run 1-3 data, resolving
  issues with:
  \begin{itemize}
  \item the binning of FC contours;
  \item stopping an uneccessary subtraction that forced the minimum to 0
    (we were constraining ourselves to the
    'grid', when we have a better best fit that has been subtracted)
    for FC contours;
  \item using finer binning in $\Delta m^2_{32}$ for the '2+N' fit.
  \end{itemize}
  Figures 65, 71-79, 82 {\color{red}(69, 75-83, 86)}.

\item
  Update the star plots; it was found that the -1$\sigma$ fit was done
  for a toy experiment created at the +1$\sigma$ best fit point, rather
  than the test point. This caused the asymmetric errors.
  Figures 24-27, 262-373 {\color{red}(24-27, 266-277)} and Table 12
  {\color{red}(12)}.
  The response to Phillip L.'s comment number 6 in this document has
  also been revised.

\item
  Add a new section, 5.4, in which 1D limits on the oscillation
  parameters are shown.


\end{itemize}
