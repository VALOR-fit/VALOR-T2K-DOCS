\section {Summary of systematic parameters }
\label{sec:systematics}

This analysis considers 44 systematic parameters which can be grouped into 4 categories:
\begin{enumerate}
\item SuperK energy scale (1 parameter).
\item SuperK detector efficiency \& intranuclear and secondary interactions (6 parameters).
\item Correlated flux and cross-section parameters tuned by the BANFF group to ND280 data (23 parameters).
\item Uncorrelated cross section (11 parameters).
\item \emph{Non-23 sector} oscillation parameters (3 parameters).
\end{enumerate}
A detailed description of the systematic uncertainties considered in this analysis and their
implementation can be found in Sec.\ 3 of  Ref.\ \cite{OurRun123DisappAnalysis3Flavour}.
All changes in this analysis with respect to Ref.\ \cite{OurRun123DisappAnalysis3Flavour}
are summarized in Sec.\ \ref{sec:changes} of this note.
For convenience, a summary of all the systematic parameters considered in the present
analysis is shown in Tab.\ \ref{tab:input_uncertainties}.
These systematic parameters are applied to the SuperK MC templates as 
shown in Tab.\ \ref{tab:apply_syst_to_templates}.
